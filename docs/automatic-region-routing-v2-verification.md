## 确定性修复 + DeepSeek（分支 `codex/auto-v2-deterministic-repair`）

从 `5f8a4cd` 新建分支。原则：语义判断仍由模型给出；几何、记账和格式上程序能精确判定的偏差，由程序修复并逐条记录（`program_repair` / `program_alignment` / `scope_adjustment` / `layout-repair.json`），原始模型答复按哈希保留，严格校验器本身不放宽。

### 模型与隔离

- 模型 `deepseek-flash`，由服务器 worker 以 `credential_mode: key_file` 直连 `https://api.deepseek.com`。密钥只在服务器文件（权限 600），不在仓库、本地配置或日志；worker 对返回内容和错误信息做密钥脱敏。**验证结束后建议轮换该密钥。**
- 独立目录 `/data/workspaces/image2ppt-auto-20261026-ds1` 与 OCR 隔离目录 `auto-validation-20261026-ds1`；impl1 目录、vision 仓库和生产容器未改动。
- `body_adapter` 删除 `enable_thinking` 并设置 `thinking: {type: disabled}`。开启思考时单次作者调用的推理 token 可达 1.5 万，超出输出上限导致 `model_response_incomplete`。
