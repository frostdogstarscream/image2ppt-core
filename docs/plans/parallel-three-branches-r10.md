# 三分支独立重建架构修改计划（r10）

状态：三分支待复核主链路已实现；真实质量资格仍未通过，不能视为整个计划已验收。基线：`066bc9e44cdcdd5e8375b64b048a864d9280d405`。独立分支：`codex/parallel-three-branches-r10`。

## 目标与边界

文字、素材、背景直接独立产证据，经两次屏障统一重建；不以旧 VisualPage 规划或串行流程为前置或失败补救。保留历史工作区、服务、原始图像及全部完成版本。源图是设计参照，文字内容、布局及强调不得改写。不修改公共 SlideIR 或固定编译器。

支持现有 PNG/JPEG/WebP。共享不可变源图快照及每源一次的 LayerD 结果。默认 `parallel_review`；`parallel_shadow` 仅诊断；`parallel_auto` 必须通过发布资格门禁；拒绝 `serial`。`object_extraction` 只限制素材算法，不关闭三分支。

## 架构与同步屏障

1. 文字分支一次运行本地 PP-OCRv4（有效缓存可复用），记录文字、置信度、多边形；MoMA 判断段落、角色、强调及依附。OCR 框不是字形 Mask。
2. 素材分支从源图、原始 LayerD RGBA 和 MoMA 生成对象意图、部件、排除范围及图层证据；此时不删除节点、修补背景或发布资产。
3. 背景分支生成底色、卡片、底板、连线和装饰候选及几何/颜色依据；复杂区域保留栅格。
4. 屏障一融合为 SceneGraph，持久 ID 沿用，不因改名或坐标修订变化。归属记录 RESOLVED/AMBIGUOUS/UNOWNED；Logo 内嵌文字不误作外部文字。按透明度及可见贡献处理重叠，关系不自动变为 PPT 分组。
5. 三分支受约束重建：安装字体的可编辑文字；稳定 PNG 优先锁定，再按需要生成 Alpha/Source Unmix/SAM 候选；背景原生/栅格候选及有归属证明的修补。Unmix 接受融合证据，不依赖最终 SlideIR。
6. 屏障二将文字、素材、完整旧 owner、背景修补、遮挡合为不可分事务。仅操作不可变暂存场景。单一适配层将 SceneGraph 转为既有 SlideIR。
7. 固定编译、成品回渲染、Go 独立复核和实际 PowerPoint 编辑/保存重开后提交。

新图首先建立原图保底场景；只有确认像素归属和替代对象后清理原图。禁止旧字未清除就叠加新字。不安全时保留完整原图，标记未完成可编辑重建，绝不调用旧串行补救。

## 内部协议、持久化与资源

新增 TextEvidence/1、AssetEvidence/1、SurfaceEvidence/1、SceneGraph/1 及事务记录；携带源 SHA、尺寸、坐标变换、方法版本、哈希引用。原模型回复不可变，LogicalObjects/1、/2 显式适配。

SQLite 持久化分支、证据、候选、依赖、外部调用预留和场景提交。调用先预留，未知结果不自动重发同一收费请求；有原始回复恢复解析。缓存分别绑定证据输入、影响像素的定义、场景关系与 QA。名称和普通描述不触发重抠。

初始并发：页面 2、CPU 重任务 2、MoMA 2、Go 1、每主机 Office 1、编译 1、每 GPU 1。LayerD/SAM 共用跨进程 GPU 锁，覆盖加载和推理；不终止其他产品。OCR 校验本机三个 ONNX 并使用只读路径，任务不隐式下载。

每对象至多六个候选、两次实质规划修复、两组 SAM 提示；文字/背景修复各两次。仅重算依赖子图，稳定素材字节不重新采样。

场景/资产/QA 先形成不可变完整 generation；最终通过任务 generation CAS 更新唯一交付指针，Registry 作为已提交场景的索引。候选阶段、自动质量、人工作业分开；REVIEW_REQUIRED 回退不算透明成功。

## 验收

架构独立性；原文/数字/强调/中西文字体；真实文字与框内空白区别；深蓝底白字、Logo 内嵌文字和标签/箭头/卡片关系；完整云图两个 owner、离散部件、建筑、白色有效内容、孔洞、软 Alpha、细线和阴影。

故障注入覆盖错 SHA、半个 owner、分组、分支/GPU/Office/Go 异常、CAS 冲突和提交中断。缓存复用不得重复分层或收费；改文字不改变稳定 PNG 字节；背景和保护区变化须重新验收。

固定编译链和实际 PowerPoint 移动、缩放、删除、保存重开；事务外像素变化为 0。未知证据不得通过。自动门禁、人工作业、WPS 分开。运行产品/规划器/新编排器/资源测试及 `./image2ppt.ps1 test`；若改编译器或 OOXML 再执行 synthetic demo、check_demo 和真实预览。

交付仅新版 PPTX、12 页预览和简短说明。后台保留完整失败、候选、调用、归属及 QA。未满足全部必要门禁时不开放 parallel_auto，不声称全页全部独立可编辑；人工验收始终由用户确认。
