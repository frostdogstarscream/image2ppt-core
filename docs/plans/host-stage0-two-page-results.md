## 宿主与模型记录

- Stage 0 在 Agent 会话建立前完成。两页 OCR 分别产生 94 和 70 行。LayerD 两页均就绪，4090 上的 PP-DocLayoutV3、PP-DocLayout-L、DocLayout-YOLO 和 OmniParser 均在两页返回了候选。两页各产生 16 个空间区块，单块编号数最多分别为 25 和 22。
- 宿主在 39.22 分钟时冻结基线。45 分钟检查点已经合成 PPTX，两页分别提交 50 和 18 个对象。约 48.69 分钟时记录了最终交付选择。
- 基线阶段 LLM 轮次与 token 数均为零。B 组记录到 32 条助手消息，输入 165,368 token，输出 8,590 token，推理 29,032 token。以上为 OpenCode 分项记录。供应方返回费用为 0。
- Agent 写入 4 次编号规划，请求 8 次增量重建。1 次被范围校验拒绝，7 次执行均返回 `NO_CANDIDATES_STAGED`。其中出现了背景复杂、相邻文字重叠和素材分离证据不足。Agent 增量提交数为 0，最终比较没有触发退化回退。
- Agent 自评通过。未执行独立 Go 复核，人工与 WPS 均未验收。
