## 通用实现及修正

- 模型执行 OCR、对象清单、局部查看、素材提取、图像归属调整、清字底板生成、字体测量、SlideIR 生成、编译和复审。
- 父素材记录已清除子对象的依赖，编译时核对子对象存在且位于父对象上方。历史素材从已保存的动作及底板哈希恢复依赖，原 PNG 字节保持稳定。
- 重复图像细节检查同时要求原图和两个素材具有局部笔画，避免平色修补区域恰好接近原图颜色时误报。
- 模型可按自身对象清单区域调整界面内在文字的归属，失效清字素材会被取消选中，之后由模型重新提取。
- 平滑区域复用背景面拟合，仅修改有源笔画证据的修复掩码。复杂区域继续保留既有修补及诊断。
- 编译反馈最终 PPTX、去原生字后的实际 PPTX 和程序定位的残影区域对照图。恢复后需成功重新编译才能结束。
- 默认每次执行上限调整为 120 轮，达到上限后保留检查点并支持恢复。模型请求预约、未知响应停止、429 退避、任务文件锁、原子检查点和有效候选保留继续生效。

Codex 的人工参与包括通用执行器开发、诊断产物查看和任务恢复。页面内容、坐标、样式、素材选择及修正动作由运行中的模型产生。首轮、失败候选和所有中间构建保留在各自 `runs/image-only-*` 目录中。
