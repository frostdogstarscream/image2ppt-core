# 从实际编辑排查 OpenCode 的误判

2026-11-25。本次对照从 `dfb949d` 的 OpenCode 研究工作树开始。检查对象是“在成品里改字或移走东西后，原处和邻项会怎样”。涉及同一页的几次实验证据不能相加成一次整页通过率。

| 环节 | 实际问题 | 处理及依据 |
| --- | --- | --- |
| 工程说明 | 两份技能把流程放在首位。工程技能让调试者先读多份手册，容易忽略用户看到的具体缺陷。 | 工程技能与工程说明改为从用户要做的编辑和真实文件入手。工具用法作为参考。 |
| 文档测试 | 工程技能即使含义正确，仅因缺少几句指定英文原话，协议套件也会失败。 | 保留自动入口、冻结对照入口及已安装副本的一致性检查。具体裁切、编辑和回退行为以产品测试验收。固定编译器与公开 SlideIR 没有改动。 |
| Agent 启动 | `runner.prepare_workspace` 将全文用作系统提示，又复制一份可加载的技能。首次请求要求调用技能。普通入口也收到了预计算基线的指引。 | 每个入口只发送一份适用的任务说明。预计算入口可以取得每页的原图证据，普通入口直接附图。使用请求捕获测试核对实际发送的内容。 |
| 找到问题与重试 | `host_evidence.scoped_ids` 将主机的问题清单当成允许修复的对象全集。即使找到了新线索，同一对象试过两次之后也会被拒。 | 主机仍提供建议。Agent 可以选择本页与原图绑定的其他编号。检查每个对象所有试过的证据和方案；新证据允许再试，重复方案跳过。提交仍由实际像素归属和 Office 检查决定。 |
| OCR 与图标 | OCR 可以读错高置信汉字，也可能把图标轮廓读成一个字母。`graphic_readings.bind_graphic_readings` 与业务文字判定是不同的检查。 | 能否编辑和原文是否确认分别记录。一个字母可以是真实单位，不能凭字数删除。此轮没有重新训练 OCR 或验证新模板的识别率。 |
| 底色选择 | `region_text.choose_region_background` 原先在环带和整体填色上作比较。层间颜色很接近时，一整行仍可留下淡淡的字形。 | 查看原笔画与同一表面露出的邻近底色。候选底色带有旧字时尝试其他候选或已有的局部拟合，只改有归属的笔画。原始分层仍可被选中。 |
| 删除后检验 | `inspect_residuals` 会拿旧的局部底色估计和删除截图作比较。底部实际多了一条原生标签时，正确的颜色也能被当成残留。 | 对具备完整回执的单行文字，核对真实删除图和成品内底图；连贯笔画、有效标点、邻项受损或证据不匹配仍需处理。第 08 页历史 33 个真实删除中，两个短编号和一个小标题纠正了判定，另外 30 个结果一致。 |
| 字框与邻项 | Office 的文字宽度估计和真实可见笔画不同。4 个框外像素也可能是连在一起的深色笔画。 | 用三份历史文件在 PowerPoint 新做 12 次换字保存重开。只有「山→编」「6→8」各两种替换由失败改为通过。旧字、新字都在原框内，临时加宽后画面相同。实际越框的深色笔画继续报告。 |
| 复杂对象和交付 | 一处未完成的文字，曾使用户拿不到已经含有数十个可编辑对象且通过 Office 检查的研究稿。 | `host_baseline._verified_partial_copy` 让逐页已有真实编辑、文件身份相符、仅余文字问题的文件可下载，保留问题清单并标记部分可编辑。整页图片无法借此交付。图片、箭头等是否拆出仍看实际对象及其编辑。 |
| 整页评分 | 对同一输入的控制组比较会同时看可编辑对象、已有编辑是否保住、文字覆盖和图像相似度。整页相似度看不出淡字，也证明不了能够单改一个词。 | 继续将原图及实际编辑对照与总分分别报告。未发现具体误判的颜色和形状阈值记录为待更多样本验证。 |

自动链路仍有待实测的缺口。原任务中的照片、右侧箭头与页眉仍有内容落在栅格层。本轮三处清底修改不会把这些对象变得可移动。局部编号重建默认关闭通用区域裁图，缺少安全的独立对象时仍会留下原像素。受检单字的字形宽度复判也不能推广到所有多行文字。单张开发页无法给出陌生模板的覆盖率。

## 第 08 页验证边界

从原任务 Office 候选出发，复用原图与当时实际保留的分层，让产品重做三个文字区域，再用固定编译器生成整页。逐个替换三个文本框，在单独副本中删除它们，保存、关闭、重开。新旧删除图上，旧笔画相对邻近底色的色差 P90 分别从 9 到 4、4 到 0、9 到 4（尺度 0–255）。三次替换的内容和邻项均核对过。这是对原任务的页面级回放，不是重新上传或重新识别一张陌生图片。

新稿保留 40 个原已选对象和 44 个导出节点。三处原先的字号、文本框位置和大小保留。重新暂存改变了部分内部图层序号。嵌入底图改变的 11,759 个像素均在这三段原笔画范围内。另加入“一行十个字仅剩一个旧字”的反例，逐字复查旧笔画；重算得到的整页编译输入和图片资产与已测稿一致。

另在隔离 API 中回放两个历史任务的文件选择和下载，下载字节与已有 Office 回执绑定的文件一致。该试验只验证部分稿可取得。此次没有把历史整页图表、照片或卡片的编辑算入通过数。两页的独立模型复核、人工和 WPS 验收均未在此轮执行。
