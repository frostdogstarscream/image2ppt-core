## 缓存与策略

`recovery/asset_cache.py` 统一 L1/L2 指纹。L1 覆盖本地 Python 产品与重建依赖、共享资源租约、源图、场景、对象、父区域、全部 LayerD 文件、模型绑定和 Python 运行时版本。新增、移除及修改依赖文件都会改变映射。

L2 额外覆盖实际字体配置与字体文件、全部候选文件、固定编译器实现、实际加载的引擎及传递依赖、finalizer、Node／Python 和 PowerPoint 可执行文件。缓存命中前重新核对输入指纹和验收产物哈希。完整性校验继续执行。

每个目标依次尝试现有 Alpha／Source Unmix、经源像素验证的背景上下文、按需 SAM。保护证据相同时跳过重复的背景上下文策略。首次合法候选停止搜索。SAM 支持的完整 LayerD 组装可以作为既有 Source Unmix 的范围先验，随后仍重新推导完整源组件及擦除授权。原始 SAM Mask 不直接成为擦除 Mask。

源组件、背景或 Owner 失败时保留当前对象回退。合成故障注入覆盖第二个素材失败时第一个素材继续保留，以及本地候选可接受时不调用 SAM。

```powershell
python services/product/run_batch_assets.py `
  --job outputs/r12-icon-final `
  --layers outputs/r1206-fresh/fresh-cache/layers/3f1daa8db89fd43e9a595361fcc320283cf456eea867c9c2b9bcf54adc91d371-4228be1a8affda14 `
  --output outputs/r1208-batch --limit 5 --sam-budget 5
```

增加 `--office`，仅为合法候选执行 L2。相同输入与代码会复用 L1、L2 和暂存结果。`failure-inventory.json` 包含全部剩余素材的原失败收据和分类，`batch-l2.json` 包含逐对象结果与独立通过的候选目录。

正式组合使用已有产品回归入口。

