## 模型接入

现有服务器凭据通过 Dify 租户解密机制在服务器内存中使用。模型目录包含 75 个 ID；
`qwen/qwen3-vl-plus` 已通过随机字符、颜色、形状识别与结构化 JSON 小图测试，
并通过流式响应测试。首选在真实页连续未通过规划协议后，验证了备用
`hacm/qwen2.5-vl-32b-instruct`，收到 HTTP 402；未将其用于真实页面。
这仅证实本轮调用被拒绝，未据此推断具体余额或授权配置原因。

小图接入成功不等于复杂页面规划成功。首次完整文字方案请求曾超时；随后采用
源图字体测量、完整图形规划和稀疏文字覆盖，展开为受验证的 `ElementPlan/3`。
曾观察到 12,000 tokens 输出截断，截断响应不会用于构建。最终单次请求允许最高
24,000 输出 tokens、480 秒，同时仍受每页 8 次请求及 1800 秒总预算约束。
中断恢复不重置这两个页级预算，全部请求和历史目录保留。

在真实草案中发现模型混用 xyxy 与 xywh，旧草案被严格拒绝，未手工修改后用于编译。
随后增加 `ElementPlanDraft/2` 显式归一化坐标声明及确定性转换，并从原图创建新验证任务。
随后针对真实错误增加源图裁剪文字归属诊断，为模型列出实际包含／跨越的 OCR ID；
诊断不修改原答复或页面方案，也不放宽验证。
