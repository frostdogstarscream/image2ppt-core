# Stop conditions and useful next steps

- **Owner conflict:** inspect conflict overlay and exact protected-object evidence, then propose a complete closure or explain what is unknown. Never remove protection to increase native counts.
- **Missing joint adapter:** return NOT_IMPLEMENTED, identify the intended real objects and required algorithm. Do not call it repeatedly or simulate it with a raster replacement.
- **Invalid model JSON/extra fields:** no action executes. Keep INVALID and the original provider receipt. A new corrected request is a new budgeted decision, not a silent repair.
- **Changed source/scene/asset/skill:** reject the stale binding. Create a new explicitly bound session after host revalidation; do not reuse old quality claims.
- **Model/network timeout:** UNKNOWN, preserve reservation, no identical paid retry. Evidence inspection may continue locally if the session budget permits.
- **Office or independent Go absent:** existing edit tests can be reported by their actual recorded scope, but missing QA stays UNKNOWN. Do not substitute synthetic tests for real Office.
- **Final vs TEST-COPY ambiguity:** ask for explicit image roles. Test replacement strings are expected only in marked test copies; content in FINAL_NORMAL_UNEDITED must still match source.
- **No progress/budget exhausted:** stop the region, retain source representation and list the smallest missing evidence or tool. Do not mark the page complete.
