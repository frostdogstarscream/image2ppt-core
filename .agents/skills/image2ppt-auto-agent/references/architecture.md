# Responsibility and execution

Three branches produce text, complete-asset and surface evidence for the same frozen source. SceneGraph resolves ownership and relations. The agent observes that result; it cannot rewrite it. Suggestions about a larger region remain proposals until a separate deterministic closure validator proves them.

The host supplies a page overview and an allowlist of source-bound evidence. A page plan identifies useful regions; a step requests one tool. Each decision, input binding, tool outcome and budget reservation is durable. Skill bytes and all bundled schemas are hashed into the session. A changed policy needs a new session and model-call identity.

MVP modes are `agent_shadow` and `agent_review`, both read-only with respect to production. Review mode describes existing candidate evidence and cannot grant acceptance. `off` skips the service; `agent_assisted` is unavailable. The production pipeline remains unchanged during this milestone. A local CLI/API can replay frozen evidence; it is not an upload hook.

The fixed compiler and public SlideIR stay downstream of the existing SceneGraph adapter. LayerD/SAM, Office and Go remain separate resources with their own gates. No skill prompt replaces any of these implementations.
