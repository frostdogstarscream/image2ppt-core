# Regional reconstruction choices

For text, prefer native text when source wording agrees with OCR and source ink/backing can be independently proved. T1 exact and T2 soft-alpha are candidate methods, not automatic PASS. An unresolved neighboring symbol, mixed shadow or background uncertainty requires inspection before choosing a larger transaction.

For logos and complex illustrations, preserve the complete semantic PNG, including disconnected parts, holes and real white content. A collection of cut fragments does not establish an independently editable icon. Keep stable asset bytes; requesting a new strategy does not invalidate their evidence.

For mixed cards, distinguish title, body, icon, tags and backing. A local background PNG plus native text can be useful if the tool proves old strokes are cleared and neighbors retained. Count only tested native text as native text gain; a card-shaped PNG is not a native shape. Whole-card movement does not establish independent editing of raster children.

When `PROTECTED_NEIGHBOR` or owner conflict occurs, inspect exact conflicting components and protected-object provenance. Distinguish bbox collision, real shared strokes, expanded candidate masks and background connectivity. A joint request must include the backing and relevant old owners that actually exist in the scene. Never resolve a conflict by asking to ignore or clear the protected mask.

For a cloud and overlapping label, inspect the complete cloud, text and backing first. If the generic joint algorithm is unavailable, stop with the required evidence and a proposed closure. A validated card algorithm is not proof that this closure is implemented.

Fallback preserves uncertain source pixels locally. It is a safe representation, not editable completion. An unrelated region can still make progress; shared font style alone does not create a pixel dependency.
