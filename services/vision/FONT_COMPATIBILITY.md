# 字体参数与固定文本框相容性

这一阶段是独立模型结果之后的显式后处理，不用于评价模型一次调用的原始能力。原始 FontPlan 和所有输出版本保留。字体族、基础字重由模型候选提供；本地只调整字号，然后根据实际 PPTX 回渲染选择候选或保留基准。

## 边界

- 固定文字、文本框、颜色、runs、素材、图形、层级及画布。
- 对单行且不自动换行的文本，根据本机对应字体的中西文度量求字号上限。
- 宽高限制取 `source_text_bbox` 与现有文本框的较小值。OCR 边界只作为可疑越界的约束，不作为原字体真值。
- 缺少精确字重的本机字体文件时不使用普通字重代测；该对象标为待复核。
- 允许缩小过大字号；仅当宽高两项估计比例接近时允许至多 20% 的放大。小于 5 源像素或缩小到模型值 20% 以下时不自动应用。
- 字体度量是逐字 advance 之和，不模拟完整 PowerPoint 排版、字偶距或字体替换。最终必须检查真实 PPTX。
- 这一版不自动重分配语义样式，不自行把宋体改成雅黑；模型样式不佳时允许保留已有基准参数，并记录选择。

## 有界流程

1. `constrain`：产生一个字号约束候选版本。
2. 使用既有编译器导出实际 PPTX 和回渲染。
3. `select`：按文本对象比较候选和基准的源图区域差异。区域包含源文字边界、固定文本框和估算字形影响范围，并保留 4 个目标像素边距；避免仅比较被裁掉文字后的空白区域。
4. 候选满足本地宽高限制、基础字重与基准一致，且区域 RGB 平均绝对差至少降低 0.20，才提名采用。否则保留基准。像素差可能偏好细字；在没有专门的源图字重验证之前，不接受基础字重变化。
5. 再次编译组合版本，执行 `verify`。要求全页差异改善、所有选中区域不出现超过 0.05 的退化、选中区域包络之外像素完全不变。

以上阈值是当前实验的显式策略参数，不是经过普遍验证的质量标准。区域可能包含邻居或遮挡，因此组合版还须查看实际预览。`PASS_COMPUTATIONAL_GATES` 只代表同一样例上的计算检查通过，不是字体识别准确率、泛化效果或人类验收。

## 命令

```powershell
python -X utf8 scripts/font_compatibility.py constrain --ir <模型字体版/slideir.json> --output <新的字号约束版目录>
# 通过 scripts/compose_text_ledger.mjs 编译字号约束版。
python -X utf8 scripts/font_compatibility.py select --baseline <基准/slideir.json> --candidate <约束版/slideir.json> --baseline-pptx <基准PPTX> --baseline-preview <基准实际预览> --baseline-slide 3 --candidate-pptx <候选PPTX> --candidate-preview <候选实际预览> --output <新的选择版目录>
# 再编译选择版。
python -X utf8 scripts/font_compatibility.py verify --baseline <基准/slideir.json> --selected <选择版/slideir.json> --baseline-pptx <基准PPTX> --baseline-preview <基准实际预览> --baseline-slide 3 --selected-pptx <选择版PPTX> --selected-preview <选择版实际预览> --report <新的验证JSON>
```

实际预览必须来自当前编译器的 `quality.json` 所声明路径，且该记录中的 PPTX、IR 哈希应匹配。选择时记录预览哈希，最终验证时再次核对基准预览；该机制是本地实验的证据绑定，不是外部文件的可信签名。

## 第 05 页实测

104 个原生文本中，103 个能够测量，101 个字号发生调整，1 个因缺少对应字重而待复核。首轮区域筛选选中 24 个，放大对照发现像素指标会偏好细字，因而加入字重保护。最终 v2 采用 12 个候选参数，92 个保留基准参数。

冻结基准全页平均绝对差为 17.89239；原始模型版为 20.38197；最终 v2 为 17.80201。首轮 v1 的指标为 17.65262，但包含未获单独证据支持的字重变细，因此不因数值更低而选择它。改善有限，模块布局、背景、图标等问题仍存在。v2 选中区域之外 884175 个像素完全一致，12 个选中区域的差异均未退化，104 个文本的实际字体声明和内容检查通过。

这是单页工程试验，不建立多页准确率，也没有执行 PowerPoint/WPS 打开编辑或人工验收。
