# 元素拆解与监督复检实验

2026-10-20 增加 [视觉模型字体参数接入](FONT_PLANNING.md)：新请求使用 ElementPlan/2 显式提供字体；也可以使用 FontPlan/1 冻结文字和布局，仅更新字体族、字号、字重。旧请求与结果保持原样。

目标是把卡片底板、标题条、箭头、图标和文字分别输出为独立对象，避免仅把 OCR 文字盖在整页残差图片上。该实验保留原流程和历史结果，不改变默认模型或正式服务接口。

## 数据流和边界

1. 复用与原图 SHA256 绑定的本地 OCR。文字识别由已有 OCR 引擎完成；OpenCV 用于几何候选提取，不充当 OCR 引擎。
2. `element_inventory.build_inventory` 同时保留原始边缘和排除 OCR 区域后的边缘，通过多阈值轮廓、颜色连通区域产生候选框、轮廓、嵌套关系及 OCR 交叉关系。它不修改原像素，不把候选自动认定为真实语义对象。
3. 视觉规划模型读取原图、OCR、候选清单和候选缩略图，生成 `ElementPlan/1`。简单底板/线条/箭头用原生形状，复杂图标用局部图片。每一个 OCR ID 必须明确选择原生文字或保留在某个局部图片中。
4. `supervised_elements.materialize_elements` 验证来源、坐标、对象 ID、文字归属，禁止面积超过页面 18% 的单一图片回退，并拒绝与原生文字重叠的原始栅格文字。底层输出标准 SlideIR，由现有固定编译器生成 PPTX。
5. 独立模型读取原图、实际 PPTX 回渲染预览、局部图片清单，以及直接从 PPTX XML 提取的原生对象和文字清单，输出逐问题复检报告。模型 PASS 不等于人工或 PowerPoint/WPS 验收。

18% 是本实验的防止大图回退约束，不是普适的幻灯片质量阈值；复杂照片可能需要另行设计有证据的例外。本实验不静默放宽它，也不自动把未支持的形状拼成整页大图。

## 运行入口

本轮输入固定为 `outputs/supervised-elements-20261019/inventory-v2/{02,03,05}`，数据来自已有源图及 OCR，输出目录必须是新的。根目录脚本：

- `scripts/prepare_supervised_element_jobs.py`：准备三页规划请求；不联网、不读凭据。
- `scripts/run_supervised_jobs_secure.py <实验目录>`：在隐藏输入中接收凭据，执行指定任务名；最多三个并发请求，每个任务只尝试一次，已有响应不覆盖。仅在用户明确授权外发的数据和目标接口后调用。
- `scripts/supervised_element_pilot.py materialize --page 02`：校验原始响应并生成独立对象 IR。
- `./image2ppt.ps1 compile -InputPath <本轮slideir.json>`：通过固定编译器导出及回渲染实际 PPTX。
- `scripts/supervised_element_pilot.py review --page 02 --build <实际编译输出目录>`：为独立监督模型准备请求。

本轮计划使用 `kimi/kimi-k2.6` 规划、`qwen/qwen3-vl-plus` 复检，均经用户指定的 OpenAI-compatible 接口。HTTP 接收成功仅证明完成传输；模型名称、文字正确性、几何准确性和实际可编辑性需分别检查。原始请求和响应留在本地实验目录，不能把这些可能含页面内容的文件当作可公开日志。

## 明确未承诺的能力

原生形状参数目前是模型提案；旧重建器的纯色形状像素门禁不会被误标为已通过。实际渲染和独立复检仍可判定失败。局部图标的内部像素不可编辑。简单白色背景可能遗漏复杂装饰纹理，必须在缺失项中记录。扁平对象拆解尚未自动生成可验证的语义嵌套分组。本轮不建立独立 API 模型排行榜，不覆盖任何旧结果，不声明人工验收。


## 本轮新增验证与结果边界

长规划超时后采用对象清单、文字决策两个 Kimi 请求，使用源图哈希绑定合并。ElementPatch 支持保留未指定字段的字段补丁，null 删除可选字段；原始响应不修改。`element_calibration.py` 对通过本地字形拟合的文字测量字体、字号、颜色和位置，并对排除子元素后的可靠纯色底板测量填充；拒绝的项继续待复核。

独立 Qwen 监督读实际文件预览，并增加不提供 OCR 转录的盲检版本，避免将 OCR 错误当作标准答案。实测监督仍会误报，因此其意见不自动写回，FAIL/PASS 都不能替代本地证据或人工验收。具体结果在 `outputs/supervised-elements-20261019/RESULTS.md`。

第 02 页的完整对象集合触发 Artifact Tool 2.8.99 导出停滞。为本轮增加显式 `compile(...,{exportBatchSize:80})` / `compose(...,...,{exportBatchSize:80})`：仍由 Artifact Tool 原生生成各对象，分批导出后合并 XML、内部图片关系及 z 顺序，再走原有适配器、完整性/布局/字体校验和实际文件回渲染。普通编译默认路径不变。该恢复路径仅支持 text/shape/image，无背景图片资产，不支持表格、图表或外部关系；超出范围明确拒绝。合成示例与实际页面均保留验证报告。局部图标仍是栅格素材，且分批导出不提升视觉还原准确率。
