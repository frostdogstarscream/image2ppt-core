## 源图与标注

`manifest.json` 给出原图相对路径、原始文件 SHA-256、解码为 RGB 后像素字节的 SHA-256 和尺寸。原图保存在现有本地输入目录。`project` 指含 `inputs/xuzhou-20261029`、`qa-inputs/xuzhou-20261103/source` 和 `PPT图片` 的数据工作区；`workbench_inputs` 指既有政务工作台原图目录。只从原图及其局部读取标注，没有读取旧 Hy4 计划、文字试验、Office 反馈或成品来确定预期答案。

原六项所在的两张开发页已按文件与解码像素哈希排除。独立性指相对于这两张开发页以及本次预先冻结的编辑目标。项目历史使用过这些素材系列，无法从现有记录证明模型或开发过程从未见过这些模板。

`cases.json` 是可直接传给 `probe_fields.py --cases` 的 JSON 数组。每项为 `[页序, 原文或目标标签, [左, 上, 宽, 高], 动作, 替换值]`。坐标对应探针的 1672 × 941 画布，本集原图尺寸也全部为 1672 × 941。

- `text` 共 21 项，使用原文匹配指定位置的文字或表格字段。第 5 页的字段用例检验能否单独改字。原生表格类型需要另查看对象结构。
- `move` 共 5 项，原标签应随指定区域向右移动。探针可用单个对象或多选完成；区分这两种行为时读取结果中的 `selection`。
- `fill` 共 9 项，目标框圈定可独立换色的形状。探针固定测试色，替换值留空。
- `delete` 共 3 项，分别圈定一张工地照片、一整张监管看板和一整张工作台界面；替换值留空。

未来的新任务上传清单中的原图，使用独立任务目录。用例、框、替换值和历史试验只留在评测侧。冻结提交没有重建结果或编辑通过率。
